# JavaScript Practice

Welcome to my personal JavaScript learning repository! This is a dedicated space where I document my coding progress, experiment with code snippets, break down complex concepts, and build out practice exercises.

The goal of this repo is to serve as a living documentation of my growth and a quick-reference guide for my future self.

## ⚙️ Environment & Setup

Most of the fundamental scripts here run directly in the terminal using Node.js, while UI exercises run right in the browser.

### Running Node.js Scripts Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/sagarpatil-17/js_practice.git
   ```
2. Navigate into the project folder:
   ```bash
   cd YOUR-REPO-NAME
   ```
3. Run any backend file using Node:
   ```bash
   node path/to/file.js
   ```
